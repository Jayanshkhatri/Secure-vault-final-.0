What response time should I expect?
+
We typically respond within 24–48 hours. For urgent cryptographic issues or security vulnerabilities, please flag your message as high priority in the subject field.
Can I contribute to SecureVault?
+
Absolutely. SecureVault is a student project and we welcome code reviews, cryptographic feedback, and collaboration from the security community. Reach out with your GitHub handle.
Is there a public API?
+
Not yet. We're considering a public encryption API endpoint for future releases. Contact us if you're interested in early access or testing partnerships.
I found a security bug — what should I do?
+
Please report it responsibly via email with full reproduction steps. We take all vulnerability disclosures seriously and will acknowledge reports within 12 hours.
